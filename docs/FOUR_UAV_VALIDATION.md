# 四机版本验证说明

当前版本默认四架 X4-950 + Airbot Play，一个共享 MuJoCo 世界，四个独立 PX4 SITL。
模型采用人工距离衰减加速度扰动叠加，不是经标定的真实尾流；PX4 使用仿真真值反馈，不能代替实机或真实传感器验收。

## 已实现与检查

- 同向 +X 的 2×2 方阵，边长 2 m，每机完整质量约 8.0004 kg。
- 四套命名空间、执行器、关节、传感器、通信身份和参数目录隔离；共享世界每步只推进一次。
- 物块 0.5 kg，四条 1.6 m 直绳分别连接实际夹爪 endpoint 与物块顶面四个 site；k=100 N/m、c=3 N·s/m。
- 四源扰动叠加、自作用为零、关闭清载荷、地面/无推力门控。
- 24 个方向按钮均有离线真实 Matplotlib canvas 点击检查；被拒绝的目标更新不会修改任何飞机目标。
- 四张曲面及等值线共 10176 个几何，单源半径 10 m，缓存与完整绘制等价。
- 保留 `--aircraft-count 2` 的双机回归入口，双机默认绳长仍为 1.2 m。

最新离线重跑：**87 passed**。命令：

## 显示性能与限制

四机面板读数默认 1 Hz（双机 2 Hz），鼠标事件 30 Hz、MuJoCo 同步 20 Hz、曲面 10 Hz 独立调度。
可用 `--panel-hz 0.5` 进一步降低读数刷新，物理步长和飞行限速不变。
四源场景仍保留完整网格。原生2Hz面板测得读数刷新约占总墙钟时间2%；主要显示开销在 MuJoCo 同步。
最终1Hz标准入口已闭环通过，但不同流程的运行时间不能用来声称1Hz带来确定比例的整机加速。
当前不保证稳定达到实时倍率1。

带载速度上限 0.25 m/s、常规加速度渐变 0.1 m/s²；物理步长 0.005 s。
独立目标的水平间距/绳长几何校验不保证任意高度差、姿态和动态过程下的绳索稳定。
PX4 原有预检状态文本保留，健康判断和解锁协议未在本轮修改。
现有预编译 PX4 未重新构建。原单机工程保护文件和运行包散列检查均未变化。

## 展示素材与复现

`demo/` 为维护者更新的四机图片与视频；README 顶部展示该视频的网页播放版。
`docs/media/four-uav-fields/` 是离线姿态的四曲面示意，没有运行 PX4 或推进物理。
`docs/media/four-uav-payload-sitl.png` 重建已通过运行的真实机体、机械臂和物块姿态；不记录转子相位。

```bash
python scripts/run_simulation.py --aircraft-count 4 --check --mode both
python scripts/run_simulation.py --aircraft-count 4 --mode both --instance-base 4
python scripts/run_simulation.py --aircraft-count 4 --headless --auto --mode both --duration 3 --timeout 300 --instance-base 4
```

开发机原始输出日志不随仓库分发。每位使用者的实际运行结果保存在自己的 `outputs/runs/`，
需区分离线检查、真实 SITL、图形检查与实机证据。
