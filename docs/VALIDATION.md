## 退出、端口与独立性

- `signal_shutdown`：向刚创建会话的 Python 拥有者发送 SIGINT；明确记录中断而非飞行成功，两个子进程清理通过。
- 真实 socket 检查：活动 TCP 监听被拒绝且保持运行；关闭端点可重新使用；TCP TIME_WAIT 不再误判成活动会话。
- 端口占用时没有结束已有进程。实例启动失败清理由离线生命周期回归另行覆盖。
- 原工程 757 个受保护文件 SHA256 全部一致，记录见 `isolation-check.json` 和原始清单。
- 运行包 90 个命令别名仅指向自身内部，无损坏或跨项目链接；归档输出不复制运行时目录链接。
- 新目录的最终复核见 `deployment-check.json`：585 个普通工程文件复制一致，部署位置独立重跑 26 项离线测试与最终关闭模式完整飞行通过；参数/状态/日志均保存在新工程自己的 outputs 下。
