# 双 X4-950 相互扰动首版设计

用户在 2026-11-12 明确批准本文模型并要求开始开发，目标目录为 `/home/raids/Dual_UAV_Interaction`。
一个 MuJoCo 世界与时钟，两架带 Airbot Play 的 X4-950、两个独立 PX4 SITL 实例。
保留原单机项目不变，不引入 PINN 或真实尾流标定假设，不修改 PX4 二进制。

世界 z 向上。以水平中心距 d、水平 A→B 单位向量 e 和 g=1/(1+(d/L)^2)，
定义 B 受 A 的加速度为 `[Ah*g*e_x,Ah*g*e_y,-Az*g]`，
A 受 B 的水平反向、竖直仍向下；Ah/Az 非负有限、L 正有限。
四模式 off/horizontal/vertical/both。模式与参数可在面板一次应用，非法输入保留上一组配置。
默认 off、Ah=Az=0.5 m/s²、L=2 m，均是可修改的演示参数，不是气动标定值。
源机无推力时不产生干扰，接收机落地/未进入飞行状态不施加载荷。
水平重合且需要水平方向时拒绝；off 或纯竖直可以有界求值。

每机在同一快照计算载荷，按各子 body 质量分配同一世界系加速度外力，
使整机合力为 m*a、关于实时整机质心的合矩为零，保留关节与 PX4 自身姿态响应。
空气作用不要求两机竖直力互为相反数。每物理步仅调用一次 mj_step。

资源、pymavlink 和 PX4 bin/etc 复制到新项目，没有指向原项目的运行依赖或可写符号链接。
通过 MjSpec attach 给两套 body/joint/site/sensor/actuator/asset 加 a/、b/ 命名空间。
默认初始水平间距 2 m、起飞高度增量 2 m。界面支持两机解锁、起飞、降落、紧急停止、退出，
模式与 Ah/Az/L、间距目标调节、实时位置与实际外力显示。首版机械臂维持初始姿态，未实现共同负载接触任务。

实例 k 使用 TCP 4560+k、Offboard UDP 14580+k、系统 ID k+1、独立参数/日志目录。
接收状态和控制必须校验来源 ID；两机发送者与浮点配对保持一致。
启动器只清理自己创建的子进程，端口被占用则报错，不结束已有进程。
提供 headless 自动悬停/降落检查和无 PX4 离线检查；分别报告测试证据与闭环证据。

实现选择：直接加速度现象模型，无训练数据要求，支持方向/幅值对照；
未选择流场加旋翼入流模型，原因是用户明确要求可调的简单互扰表现。

Python 使用类型提示与 Google Style Docstrings；随机气压噪声每实例固定 seed；无随机扰动。
