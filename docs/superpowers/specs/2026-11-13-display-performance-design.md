# 显示性能优化（用户已批准）

目的：改善用户记录约0.30倍实时的图形仿真速度，保留现有显示形状与物理效果。
输入为最新同一物理时刻快照、墙钟时间和显示开关；输出为独立节拍的面板/事件/场景更新。
当前隔离Xvfb计时：面板完整重绘约51ms、曲面重建33ms、viewer.sync约8ms，物理单步约1.5ms。

采用用户批准的第一轮方案：面板读数2Hz；事件30Hz；MuJoCo同步20Hz；曲面更新10Hz。
事件与读数分开，点击后错误/目标状态可立即更新；仍只在启动show一次。
面板保留既有按钮布局，在平坦背景的固定状态区局部清除并重画文字，避免反复绘制按钮；
原生canvas不支持局部blit时回退完整draw_idle。保存/resize后重新建立可用renderer状态。
不依赖持久animated artist，保证常规savefig和控件自己局部绘制不互相覆盖。

风场保留12×48网格、全部等值线和双源5088几何，10m半径、5cm高度偏移、L响应均不变。
只有独占非append用户场景复用mjvGeom对象，逐帧更新绝对位置与透明度；场景/源拓扑/L/容量/
清空/开关/时间回退变化时重建，append预览始终完整构建，避免污染物理前缀。

保持5ms物理步长、共享世界每步一次、PX4控制频率/协议、吊绳/互扰模型及0.25m/s、0.1m/s²带载轨迹。
第一轮不改墙钟追赶策略、不提高带载限速、不简化碰撞和曲面网格。若性能仍受硬件限制如实报告。
验证实际按钮/编辑状态不会被局部刷新抹去；缓存与全构建几何逐属性一致；控制快照不受显示影响。
以相同隔离计时协议比较，再执行原生双PX4起飞/六个独立XYZ响应/显示/降落流程，记录实时倍率和清理证据。
