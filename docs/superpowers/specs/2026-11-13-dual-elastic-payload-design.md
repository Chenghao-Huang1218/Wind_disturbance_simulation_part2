## 当前实现核对与布局提议

当前 A/B 的初始 root 四元数均为 [1,0,0,0]，机体前向均为世界 +X，飞行 yaw 目标也相同。
现有位置间距沿世界 X，因此相对机头是前后排列。
建议改为沿世界 Y 左右并排、共同朝 +X，默认位置为 [0,-1,0.48]、[0,+1,0.48]。
采用无碰撞/无质量的机头标识明确方向。机械臂继续位置伺服维持初始姿态，不锁死关节、不实施抓放。
夹爪绳端使用现有 a/endpoint、b/endpoint；参考初始 pose 中它们分别在各 root 的
[0.297014,-0.002454,-0.344061] 附近。新布局下夹爪间距约 2 m，物块中心位于两夹爪的 XY 中点。

## 弹力绳与物块动力学

沿用参考程序的无质量、仅受拉弹簧—阻尼近似。设 a 为夹爪末端、p 为对应物块吊点：

```text
r = p - a;  ell = ||r||;  n = r / ell
ell_dot = (v_p - v_a) · n
ell <= L0: T = 0
ell > L0:  T = max(0, k*(ell-L0) + c*ell_dot)
F_on_payload = -T*n; F_on_gripper = +T*n
```

零长度时返回零力；参数与输入必须有限且维度正确。阻尼沿绳方向作用，不能产生压缩推力。
每步在同一时刻读取两绳端的位置和速度，速度由 site Jacobian 与 qvel 得到，包含角速度/关节运动贡献。
用 mj_applyFT 在实际世界坐标吊点施加成对反力：夹爪端施于其所属 link6，物块端施于自由物块。
关节、机体和物块因此承受真实载荷及相应力矩；不能把夹爪反力移到 root 或事后删掉合力矩。
原人工气动互扰模型自身的零 COM 合矩规则保留，绳索载荷与气动互扰分别记录。

共享世界每步只推进一次。绳索独占当前应用的 qfrc_applied 通道，使用独立广义力累加缓冲；
每步在前置 mj_forward 之前清掉旧绳索广义外力，再累加两条绳并统一写入一次。
松弛和无载路径也要清除旧力，不能在第二条绳前清掉第一条绳的作用；
不覆盖气动互扰写入的 xfrc_applied。未来若增加其他广义力写入者，应显式重划该通道所有权。
物块使用自由关节、显式质量/惯性和地面碰撞，两个连接点随物块转动，不把物块位置直接锁在双机中点。
采用零刚度/零阻尼的空间 tendon 只负责绘制直线绳，实际张力由上述模型计算，避免双重施力。
绳不模拟质量、垂度、分段碰撞、断绳、抓放或绕障；当前只实现永久绑定的吊运连接。

## 操作与接口提议

默认启动为吊运场景，提供 --no-payload 回退无载模式用于对照。
质量、原长、刚度和阻尼作为明确配置/命令行参数；初始化校验几何与参数，不在运行中突然重绑。
已有同步起飞、公共 X/Y 移动和降落用于展示吊运，不增加专用负载姿态控制器或抗摆算法。
携载模式的初始/目标间距均暂限 1.5–2.25 m，防止沿用原 10 m 调节上限把短绳过度拉伸；
上限与现有 0.25 m 调节步幅一致。这是首版仿真操作范围，不是实物安全距离。
命令行和运行中使用相同校验，无载模式仍保留原范围。
面板显示物块位置/离地状态、两条绳长与张力；日志增加物块位姿/速度、两绳伸长/速度/张力和端点力。
metadata 记录质量、尺寸、吊点、绳参数与布局。保留双实例身份、目录隔离、端口预检和拥有者进程清理。
启动器不重新编译 PX4；当前 PX4 原生位置反馈处理额外载荷，不引入参考程序中的 L1 补偿。
每机推力换算仍基于自身子树质量，不把一半物块质量预先加入该标定来掩盖新增载荷。

1. 离线数值：松弛无力、拉紧 Hooke/阻尼符号、收缩时不推、零长度、非法输入、两端反力守恒；

   自定义配置若导致初始绳已拉紧或物块/无人机穿透，应拒绝并给出清晰原因。
   点力映射与 J_site.T @ F 对照，验证上游机械臂自由度确实受力，不要求每个关节都出现非零力矩。

   不能仅凭无人机到达 hover 阶段称吊运成功。现有 --auto 没有 XY 搬运，需明确增加吊运验证阶段。
5. 离线、静态预览、真实 SITL、人工桌面验收分别报告。暂不扩展实机、训练、固件或其他研究工程。
