# 双机独立方向控制面板

用户明确要求参考单机 uav_control_with_px4.py 的面板样式，增加两机 Takeoff、
A/B 各自独立 XYZ 平移和扰动可视化启动按钮。沿用现有 Matplotlib 是唯一必要方案，
无需新 GUI 框架或网页服务；原项目只读。需求和样式已明确，直接实现。

布局采用浅灰底、蓝 X/绿 Y/橙 Z 三角按钮；A/B 两个独立控制区，右侧共享起飞、
降落、急停、退出、步长和显示按钮，下方保留互扰参数与状态。每机显示当前位置和最终目标。
共享步长由实现者选定 0.05/0.10/0.25 m（默认 0.10 m），适配当前短绳及窄间距。
XYZ 均为 MuJoCo 公共世界坐标。一次点击只改所选机的目标，不修改另一架，继续使用原带载平滑轨迹。
目标水平间距沿用带载 1.5..2.25 m、无载 1.5..10 m；越界整次拒绝、显示错误。

Takeoff both 为一键请求：等待两机新鲜心跳、各自正常解锁确认后才调用现有同步起飞；
沿用现有 bridge 解锁协议，不更改原 CLI 自动任务语义；发出解锁命令不代表确认。
降落/急停/退出取消未完成起飞请求，避免迟到确认后重新起飞。
独立位移只允许所选机已解锁、处于 takeoff/hover，非法索引、非有限增量或超界目标不改变状态。

显示默认关闭，以 Start field / Stop field 显示状态；按钮只改变曲面显示，不改互扰模式/载荷。
显示回调失败保留上次状态。保留模式/Ah/Az/L 草稿和 Apply settings 的原子提交。

验证：离线真实模型命令隔离/拒绝/起飞确认与取消测试；真实鼠标点击三角内部和空白区域，
步长和按钮状态测试；Agg 布局渲染及原生 Xvfb/TkAgg+MuJoCo 冒烟；必要的双 PX4 独立移动验证。
实际 SITL、GUI 自动点击与人工桌面验收分别描述，不修改/重编译 PX4 或原单机项目。
